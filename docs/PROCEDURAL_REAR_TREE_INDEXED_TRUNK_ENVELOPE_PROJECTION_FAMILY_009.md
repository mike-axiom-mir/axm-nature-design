# Procedural rear-tree indexed trunk-envelope projection family 009

## Scope

This pass adds `axm.nature-branch-transition-indexed-trunk-envelope-projection-family/v0.1` on the existing Nature Procedural lane.

The repeated operation is deliberately smaller than Geometry PR #30: preserve a sample's axial position on an exact authored tapered trunk segment, reconstruct the exact regular N-sided receiver cross-section, and intersect the sample's radial ray with one polygon side. Procedural owns this reusable numeric projection only.

Geometry retains source-triangle membership, opening-loop identity, bridge topology, indexed trunk cuts, weld/remesh strategy and connected-junction authority.

## Family

The predecessor smooth family already has five owner-backed outputs: `south-low`, `north-low`, `east-mid`, `west-high`, `north-top`. This successor reuses each output's three exact diagnostic input points and projects them onto the regular indexed shell. It therefore tests fifteen exact projections across five materially different source transitions rather than one selected ring.

Each projection returns only numeric parameters: segment `t`, centerline point, local taper radius, cross-section angle, side-cell identity, side-edge interpolation, indexed radial distance, projected point, side residual, axial residual, span and smooth-to-indexed radial delta.

The exact Geometry compatibility witness separately applies the Procedural primitive to the same eight real `north-low` branch-ring inputs used by Geometry PR #30 and compares only shared numeric projection fields. Geometry triangle membership and loop/topology evidence are not consumed as Procedural authority.

## Failure bounds

The gate fails closed on source digest drift, predecessor family/file drift, receiver side-count/phase drift, Geometry head/blob drift, duplicate branch declarations, centerline degeneracy, outside-segment samples, and attempted triangle-membership / ring / cut / connected-junction / weld-remesh / Rigging / Runtime authority promotion.

## Truth boundary

A PASS means only that one topology-free regular tapered-shell projector is deterministic across the five retained owner-backed transitions and reproduces the exact shared numeric projection used by the current Geometry indexed-surface reference.

It does not prove or adopt an indexed trunk cut, connected branch/trunk mesh, triangle membership policy, bridge validity under motion, skinning, collision, normals/tangents, target-host behavior, Runtime/device performance, visual quality, UC/PF promotion, CANON or production readiness.

Truth, Agency / non-domination, Continuity and Wisdom before speed remain the merge gate.
