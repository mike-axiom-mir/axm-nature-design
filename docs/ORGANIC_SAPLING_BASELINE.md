# Organic Sapling Baseline 001

This is the first source-owned nature candidate in `axm-nature-design`: one stylized neutral sapling intended to make organic mass, taper, branch hierarchy, leaf silhouette and future deformation handoffs falsifiable before the studio claims wind response, rigging, botany or runtime readiness.

## Scope

The source contains six authored trunk points with strictly decreasing radii, five authored branch chains, six leaf clusters and six declared flex zones. Geometry is deterministic tapered segment mass plus independently authored lozenge leaf blades. Evidence is generated from the exact triangle body as OBJ plus front/side/top SVG wire views.

The candidate is deliberately sized near the existing `axm-map-design` `proxy:nature-tree-west-a` envelope. It is only a **candidate replacement**. It has not been composed into that scene and inherits none of the proxy scene's PASS.

The weather handoff records the source-owned Weather/VFX visual direction only as context. No wind is applied to this form and no force, sway, rigging or deformation claim exists.

## Evidence boundary

A structural/design PASS means this exact generated candidate is finite, index-bounded, triangle-nondegenerate and satisfies its own authored size/taper/branch-height/flex-status contracts. It does **not** establish botanical species correctness, biological growth, production topology, self-intersection freedom, rigging, deformation quality, wind physics, animation, environment composition acceptance, materials/lookdev, collision, engine import, runtime performance, gameplay value, CANON or mastery.
